# Hubble Skills

Agent skills for [Hubble](https://github.com/bholmesdev/hubble.md).

## Install

```bash
npx skills add bholmesdev/hubble-skills
```

## Skills

- `create-html-app`: Create a Hubble HTML App: a folder-local `.html` file Hubble runs as a self-contained interactive UI. Apps get access to Alpine, Tailwind, Hubble theme tokens, and the injected `hubble` runtime API.
- `edit-diagram`: Create or edit a Hubble diagram, a `.tldr` file Hubble opens in its built-in tldraw canvas. Includes a script that completes, validates, and lints diagrams with the tldraw version Hubble ships.
- `embed-html-app`: Embed an HTML App inline inside a Markdown File with an iframe.
- `review-markdown-comments`: Address Hubble review comments stored inline in Markdown CriticMarkup while preserving anchors, metadata, replies, and unrelated Markdown.
